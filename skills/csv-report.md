# CSV 报表生成流程

## 步骤

1. **检查数据**：先用 `head -5` 看表头，`wc -l` 数行数，确认编码和分隔符。
2. **数据体检**：检查空值、重复行、异常值（超出合理范围的数值列）。
3. **统计汇总**：用 python 标准库 `csv` 模块（不依赖 pandas），按需要的维度聚合。
4. **输出报告**：Markdown 格式，包含：
   - 数据概况（行数、列数、时间范围）
   - 关键指标表格
   - 3-5 条基于数据的观察结论

## 注意

- 文件超过 10 万行时改用流式逐行读取，不要一次性读入内存。
- 金额类字段注意小数精度，用 `Decimal` 或定点整数分。
- 报告中的每个结论必须能追溯到具体数字，不要写"大概""可能"。
